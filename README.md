# CC Chatbot

## Description

CC Chatbot is an AI-powered career guidance chatbot designed for students who have completed or are about to complete their schooling and exploring future educational and career opportunities.

The chatbot helps students explore different educational and career paths such as Polytechnic, ITI, Engineering, Medicine, Commerce, government jobs and other higher-study options.

## Technologies Used

* HTML
* CSS
* JavaScript
* Python
* Flask
* Gemini API

## Features

* Career guidance for students
* AI-generated responses using Gemini
* Interactive chat interface
* Web-based application
* Deployed online
  
## Future Improvements

* Chat history
* Better UI design
* More personalized career recommendations
* Mobile optimization
